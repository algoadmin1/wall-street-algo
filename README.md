
# The Wall Street Algo™

The Wall Street Algo™ is a cycle-aware, agentic market decision framework
developed by John Botti (MIT EECS).

The framework organizes structural price analysis, rule-based signals,
cycle intelligence, and contextual event awareness into a four-layer
decision architecture designed for both human investors and autonomous agents.
